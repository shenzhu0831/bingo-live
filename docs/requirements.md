# 圈圈叉叉遊戲 — 需求規格書

| 項目 | 內容 |
| --- | --- |
| 專案名稱 | 圈圈叉叉（Tic-Tac-Toe） |
| 版本 | 1.0.0 |
| 文件日期 | 2026-11-13 |
| 技術棧 | Vue 3（Composition API）、Vite、TailwindCSS |

---

## 1. 專案目的

提供一個在瀏覽器上執行的雙人（同裝置輪流）圈圈叉叉遊戲，操作直覺、支援鍵盤操作與無障礙，並能在任何螢幕尺寸下正常遊玩。

## 2. 名詞定義

| 名詞 | 說明 |
| --- | --- |
| 棋盤（Board） | 3 × 3 共 9 格的遊戲區域 |
| 格子（Cell） | 棋盤上的單一方格，狀態為空、`X` 或 `O` |
| 玩家（Player） | 兩位玩家，分別使用符號 `X` 與 `O` |
| 回合（Turn） | 當前輪到落子的玩家 |
| 勝利線（Winning Line） | 三格同符號連成的一條線（橫、直、斜） |

## 3. 使用者角色

- **玩家 X**：遊戲先手，使用符號 `X`。
- **玩家 O**：遊戲後手，使用符號 `O`。
- 兩位玩家於同一裝置、同一畫面輪流操作。

## 4. 功能需求

### FR-1 落子
- FR-1.1 玩家點擊（或以鍵盤 Enter / Space 聚焦後觸發）空格時，於該格放入當前玩家符號。
- FR-1.2 已有符號的格子不可再次落子。
- FR-1.3 遊戲結束後，所有格子皆不可落子。

### FR-2 回合切換
- FR-2.1 遊戲開始時由玩家 `X` 先手。
- FR-2.2 每次有效落子後，若遊戲尚未結束，自動切換至另一位玩家。

### FR-3 勝負判定
- FR-3.1 每次落子後檢查是否出現勝利線（3 橫、3 直、2 斜共 8 種）。
- FR-3.2 出現勝利線時，判定該符號玩家獲勝並結束遊戲。
- FR-3.3 棋盤填滿且無勝利線時，判定為平手並結束遊戲。

### FR-4 狀態顯示
- FR-4.1 遊戲進行中顯示「輪到 X」或「輪到 O」。
- FR-4.2 分出勝負時顯示「X 獲勝！」或「O 獲勝！」。
- FR-4.3 平手時顯示「平手！」。
- FR-4.4 獲勝時，以視覺方式標示構成勝利線的三個格子。

### FR-5 重新開始
- FR-5.1 提供「重新開始」按鈕。
- FR-5.2 點擊後清空棋盤、重設回合為玩家 `X`、清除勝負狀態。

## 5. 非功能需求

| 編號 | 類別 | 內容 |
| --- | --- | --- |
| NFR-1 | 無障礙 | 格子可聚焦（`tabindex`）、具 `aria-label`，支援 Enter / Space 操作；狀態列使用 `aria-live` 即時播報。 |
| NFR-2 | 響應式 | 於手機至桌機各尺寸皆正常顯示，無水平捲動。 |
| NFR-3 | 效能 | 純前端邏輯，落子後即時反應，無明顯延遲。 |
| NFR-4 | 可維護性 | 遊戲邏輯抽離至 composable，元件職責單一，命名清楚；通過 ESLint。 |
| NFR-5 | 瀏覽器支援 | 支援現代瀏覽器（Chrome、Edge、Firefox、Safari 最新版）。 |

## 6. 遊戲規則

1. 棋盤為 3 × 3 共 9 格。
2. 玩家 `X` 先手，雙方輪流於空格落子。
3. 率先將自己的符號在任一橫、直、斜方向連成三個者獲勝。
4. 9 格填滿仍無人連線則為平手。

## 7. 畫面與操作流程

```
[標題：圈圈叉叉]
        │
        ▼
[狀態列：輪到 X]
        │
        ▼
┌───┬───┬───┐
│   │   │   │
├───┼───┼───┤   ← 點擊空格落子
│   │   │   │
├───┼───┼───┤
│   │   │   │
└───┴───┴───┘
        │
        ▼
[重新開始] 按鈕
```

主流程：

1. 進入頁面，棋盤為空，狀態列顯示「輪到 X」。
2. 玩家於空格落子 → 符號填入 → 判定勝負。
3. 未結束：切換玩家，回到步驟 2。
4. 已結束：狀態列顯示結果並標示勝利線，棋盤鎖定。
5. 點擊「重新開始」→ 回到步驟 1。
