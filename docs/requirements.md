## 1. 專案目的

提供一套可供公司內部多人（約 10～20 人）同時遊玩的賓果遊戲。每位玩家在自己的 3 × 3 卡片上填入數字，由**管理員於後台手動抽號**，所有玩家卡片即時同步標記，最先連成 3 條線者獲勝。目標為操作直覺、支援鍵盤與無障礙、各螢幕尺寸皆可遊玩。

## MVP（v1）範圍

本文件以第一版最小 MVP 為實作目標，已鎖定下列決策：

- 卡片：3 × 3（9 格）
- 號碼池：**固定 1～36，不可設定**
- 獲勝門檻：連成 **3 條線**
- 平手處理：**加賽（sudden death）**，僅平手者參加、系統發新卡、先連 1 條線者勝（見 FR-6.4／FR-6.5）
- 管理員後台：**免登入**直接進入
- 玩家：輸入暱稱加入、免登入
- 即時同步：WebSocket
- 含重設場次重玩

延後至之後版本的項目見 §8（如：管理員登入、號碼池可自訂、4 × 4 卡片）。

## 2. 名詞定義

| 名詞 | 說明 |
| --- | --- |
| 場次（Game / Round） | 一局完整的賓果遊戲，由管理員開場、抽號、結束 |
| 號碼池（Number Pool） | 可抽出的數字範圍，本版固定 1～36（見 §6） |
| 卡片（Card） | 玩家的 3 × 3 共 9 格，每格填入號碼池中一個不重複數字 |
| 格子（Cell） | 卡片上的單一方格，狀態為「未標記」或「已標記」 |
| 玩家（Player） | 加入場次、填寫卡片並參與遊戲者，人數不限 |
| 管理員（Admin） | 本版免登入直接進入後台，負責開場、抽號、結束與重設場次 |
| 抽號（Draw） | 管理員手動從號碼池中抽出一個尚未抽過的數字 |
| 標記（Mark） | 抽出的號碼若存在於玩家卡片上，該格自動標記 |
| 線（Line） | 卡片上三格同時被標記連成一直線（橫、直、斜），共 8 種 |
| 賓果（Bingo） | 達成 3 條線，即為獲勝條件 |
| 加賽（Sudden Death） | 同一輪多人同時賓果（平手）時，僅平手玩家參加的快速決勝局，用以決出單一贏家（見 FR-6.4／FR-6.5） |

## 3. 使用者角色

- **管理員（Admin）**
  - 本版無須登入，直接進入後台即可操作（登入保護列為未來擴充，見 §8）。
  - 負責建立 / 開啟場次、控制抽號、宣告結束、重設場次。
  - 僅管理員可執行抽號。
- **玩家（Player）**
  - 加入當前場次並填寫自己的 3 × 3 卡片。
  - 遊戲中卡片依抽號結果自動標記，不需手動操作棋格。
  - 人數不限（預設支援約 10～20 人同時遊玩）。

## 4. 功能需求

### FR-1 後台進入（本版免登入）
- FR-1.1 本版後台無須帳號 / 密碼登入，開啟後台頁面即可直接操作抽號與場次管理功能。
- FR-1.2 管理員登入與權限保護（帳號密碼登入、登出、未登入不得操作）列為未來擴充功能（見 §8）。

### FR-2 場次管理（後台）
- FR-2.1 管理員可建立 / 開啟一個新場次。本版號碼池固定為 1～36（不可設定；可自訂範圍列為未來擴充，見 §8）。
- FR-2.2 場次有明確狀態：`等待中`（玩家填卡）→ `進行中`（開始抽號）→ `已結束`（分出勝負）；當出現平手需加賽時，於 `進行中` 與 `已結束` 之間插入 `加賽中`（sudden death，見 FR-6.4／FR-6.5）。
- FR-2.3 管理員可將場次由 `等待中` 切換為 `進行中` 開始抽號；開始後玩家不可再修改卡片。
- FR-2.4 管理員可重設場次：清除所有已抽號碼與標記、回到 `等待中`、清除勝負狀態。

### FR-3 玩家填寫卡片（前台）
- FR-3.1 玩家於 `等待中` 狀態加入場次並填寫 3 × 3 卡片。
- FR-3.2 每格填入號碼池範圍內的一個數字，同一張卡片內數字不可重複（需填滿 9 格）。
- FR-3.3 可提供「隨機產生卡片」輔助功能，由系統自動填入 9 個不重複數字（選配）。
- FR-3.4 卡片未填滿或有重複數字時，不可完成填卡；需明確提示錯誤。
- FR-3.5 場次進入 `進行中` 後，卡片鎖定不可修改。

### FR-4 抽號（後台）
- FR-4.1 場次為 `進行中` 時，管理員點擊「抽號」按鈕，系統自動從號碼池中「尚未抽過」的數字隨機抽出一個。
- FR-4.2 每個數字於同一場次內不重複抽出。
- FR-4.3 已抽出的號碼需累積顯示為「開獎紀錄」，並標示最新抽出的號碼。
- FR-4.4 號碼池全部抽完仍無人達成 3 條線時，場次結束並判定為無人獲勝（見 FR-6.3）。

### FR-5 即時標記與同步
- FR-5.1 每次抽號後，系統將抽出的號碼即時同步給所有玩家。
- FR-5.2 抽出的號碼若存在於某玩家卡片上，該格自動標記（玩家不需手動操作）。
- FR-5.3 玩家畫面即時更新：卡片標記狀態、目前已完成線數、開獎紀錄。
- FR-5.4 標記與勝負判定以後端為唯一真實來源（authoritative）：前端收到號碼後可即時標記自己卡片以加快反應，但各玩家的最終標記狀態、已完成線數與獲勝與否均以後端計算結果為準，不得僅信任前端（對應 NFR-3 安全性）。

### FR-6 勝負判定
- FR-6.1 每次抽號後，系統檢查每位玩家卡片的已完成線數（8 種線：3 橫、3 直、2 斜）。
- FR-6.2 當某玩家達成 **3 條線** 時判定為賓果（獲勝），場次結束。
- FR-6.3 號碼池抽完仍無人達成 3 條線時，判定無人獲勝並結束場次。
- FR-6.4 **同一次抽號有多位玩家同時達成 3 條線時，不直接結束，改在這些平手玩家之間進行「加賽（sudden death）」決出單一贏家**（見 FR-6.5）。
- FR-6.5 加賽（sudden death）規則：
  - FR-6.5.1 僅上一局（或上一輪加賽）平手的玩家參加，其餘玩家淘汰。
  - FR-6.5.2 系統為參賽者自動發新的 3 × 3 卡片（免重新填卡，以縮短等待），場次狀態轉為 `加賽中`。
  - FR-6.5.3 管理員重新抽號，**最先連成 1 條線者獲勝**（加賽以較快門檻決勝，門檻可調整）。
  - FR-6.5.4 若加賽又出現同一次抽號多人同時達標，則再進行一輪加賽，直到決出單一贏家。

### FR-7 狀態顯示
- FR-7.1 前台顯示目前場次狀態（等待中 / 進行中 / 已結束）。
- FR-7.2 進行中顯示：最新抽出號碼、開獎紀錄、玩家自己的卡片與目前已完成線數。
- FR-7.3 結束時顯示獲勝者（單一贏家，平手經加賽決出；或無人獲勝），並以視覺方式標示獲勝卡片上構成線的格子。
- FR-7.4 後台顯示：場次狀態、已抽號碼數 / 總數、目前領先或已達標的玩家。

### FR-8 重設 / 重新開始
- FR-8.1 管理員可結束並重設場次（對應 FR-2.4）。
- FR-8.2 重設後清空所有卡片標記、開獎紀錄與勝負狀態，回到 `等待中`。

## 5. 非功能需求

| 編號 | 類別 | 內容 |
| --- | --- | --- |
| NFR-1 | 即時同步 | 抽號結果需即時廣播給所有玩家，延遲需在可接受範圍內（例如 1 秒內）。 |
| NFR-2 | 系統架構 | 多人 + 後台統一抽號，必須採用前後端（Client-Server）架構，無法以純前端實作。 |
| NFR-3 | 安全性 | 本版後台免登入直接進入（登入保護為未來擴充，見 §8）；勝負判定與標記以後端為唯一真實來源，前端不得竄改結果，抽號等寫入操作由後端驗證合法性（如場次狀態）。 |
| NFR-4 | 無障礙 | 卡片格子可聚焦（`tabindex`）、具 `aria-label`；狀態列使用 `aria-live` 即時播報抽出的號碼與勝負結果；填卡與按鈕支援 Enter / Space。 |
| NFR-5 | 響應式 | 於手機至桌機各尺寸皆正常顯示，無水平捲動。 |
| NFR-6 | 併發 | 需支援約 10～20 位玩家同時連線於同一場次（容量上限待確認）。 |
| NFR-7 | 可維護性 | 遊戲邏輯（連線判定、抽號、狀態機）抽離為可重用模組；元件職責單一、命名清楚；通過 ESLint，遵循 DRY。 |
| NFR-8 | 瀏覽器支援 | 支援現代瀏覽器（Chrome、Edge、Firefox、Safari 最新版）。 |

## 6. 遊戲規則

1. 卡片為 3 × 3 共 9 格，每格填入號碼池（本版固定 1～36）中一個不重複的數字。
2. 管理員開啟後台（本版免登入）、開場後，於 `等待中` 狀態讓玩家填寫卡片。
3. 管理員開始抽號（手動，一次一顆），抽出的號碼於玩家卡片上存在者自動標記。
4. 卡片上三格連成一直線（橫、直、斜任一，共 8 種）即為一條線。
5. 最先達成 **3 條線** 的玩家獲勝（賓果）；同一輪多人同時達成則在平手者之間進行加賽（sudden death）決出單一贏家（見 FR-6.4／FR-6.5）。
6. 號碼池抽完仍無人達成 3 條線則判定無人獲勝。

> 本版號碼池固定為 1～36（約 2 分鐘一局，加賽不會太頻繁）。號碼池越大，玩家卡片越分散、獲勝者越明確、越少加賽，但遊戲時間越長；可自訂範圍列為未來擴充。

### 7.3 主流程

1. 管理員開啟後台（本版免登入），開場（號碼池固定 1～36），場次為 `等待中`。
2. 玩家加入場次，於 3 × 3 卡片填入 9 個不重複數字並完成填卡。
3. 管理員開始抽號，場次轉為 `進行中`，玩家卡片鎖定。
4. 管理員每次抽號 → 系統抽出未抽過的數字 → 即時同步 → 玩家卡片自動標記 → 檢查線數。
5. 有玩家達成 3 條線 → 若為單一玩家則該局結束並顯示結果；若多人同時達標 → 進入加賽（`加賽中`）：僅平手者參加、系統發新卡、重新抽號、先連 1 條線者勝（加賽再平手則續賽），決出單一贏家後結束。號碼抽完仍無人達標 → 無人獲勝結束。
6. 管理員重設場次 → 回到步驟 1 / 2。

## 8. 範圍外（本版不實作 / 未來擴充）

- **管理員後台登入 / 權限保護**：帳號密碼登入、登出、未登入者不得存取後台抽號控制與場次管理功能。本版後台免登入直接進入，此登入機制列為未來擴充。
- **號碼池可自訂範圍**：本版固定 1～36，開放管理員自訂範圍（含設定 UI）列為未來擴充。
- **4 × 4 卡片**：本版為 3 × 3，較大卡片（如 4 × 4）列為未來擴充。
- 玩家帳號系統（玩家端是否需登入，待確認；本版預設玩家免登入）。
- 跨場次計分 / 排行榜 / 連勝紀錄。
- 聊天室、表情、音效與抽號動畫。
- 自動定時抽號（本版僅管理員手動抽號）。
- AI 自動參賽者。

## 9. 驗收條件

- [ ] 開啟後台即可直接操作抽號（本版免登入）。
- [ ] 玩家能於 3 × 3 卡片填入 9 個不重複數字，重複或未填滿時有明確提示且無法完成填卡。
- [ ] 場次進入進行中後，玩家卡片鎖定不可修改。
- [ ] 管理員每次抽號皆抽出未抽過的數字，且不重複。
- [ ] 抽出的號碼即時同步至所有玩家，卡片對應格子自動標記。
- [ ] 8 種線（3 橫、3 直、2 斜）皆能正確計入線數。
- [ ] 任一玩家達成 3 條線時正確判定獲勝並結束場次、標示獲勝線。
- [ ] 同一輪多人同時達標時進入加賽（sudden death）：僅平手者參加、系統發新卡、先連 1 條線者勝，加賽再平手則續賽，最終正確決出單一贏家。
- [ ] 號碼池抽完無人達標時正確判定無人獲勝。
- [ ] 重設場次能完整清除卡片標記、開獎紀錄與勝負狀態。
- [ ] 前後台狀態顯示與實際狀態一致。
- [ ] 可用鍵盤完成填卡與主要操作；狀態以 `aria-live` 播報。
- [ ] 手機與桌機尺寸皆正常顯示。
- [ ] `npm run lint` 通過。
