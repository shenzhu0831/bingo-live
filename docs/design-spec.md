## 2. 玩家前台 — 點陣像素 + 紅金尾牙風

### 2.1 風格規範

| 類別 | 規範 |
| --- | --- |
| 整體調性 | 8-bit 復古電玩感（紅白機 FC），延續尾牙刮刮樂視覺 |
| 字型 | 英數：`Press Start 2P`；中文：`DotGothic16`（Google Fonts 載入） |
| 像素渲染 | `image-rendering: pixelated`、關閉字型平滑、無圓角 |
| 邊框 | 硬邊 4px 黑色描邊 `#08050f`（像素單位 `--px: 4px`） |
| 立體感 | 多層 offset 硬 `box-shadow`（非模糊）做 8-bit 立體塊；按鈕 `:active` 下移 4px、外陰影收合 |
| 動畫 | 標記格/獲勝線用像素閃爍或脈動（像素星星、✦）；須支援 `prefers-reduced-motion: reduce` 關閉 |

### 2.2 配色（沿用 scratch-card `src/styles/global.css` 的 `:root`）

| 用途 | 色碼 |
| --- | --- |
| 深夜星空背景 | `#0f0a24` / `#1a1340` / `#2a1f5c` |
| 近黑描邊 | `#08050f` |
| 主色紅 | `#e63946`（深 `#b8222e` / `#7a131c`、亮 `#ff6b76`） |
| 強調金 | `#ffd23f`（深 `#f4a93a` / `#b4791d`、亮 `#fff09a`） |
| 奶油字 | `#fff4d6` |

### 2.3 背景資產（沿用 scratch-card）

- 桌機：`src/assets/pixel-sky-desktop.svg`
- 手機：`src/assets/pixel-sky-mobile.svg`
- 作法：依視窗寬度切換桌機/手機版星空 SVG 鋪滿整頁背景。

### 2.4 需設計的前台畫面

1. **填卡畫面（等待中）**：3×3 空白卡片可輸入 1~36 數字；「隨機產生卡片」「完成填卡」像素按鈕；數字重複或未填滿的錯誤提示（FR-3.4）；狀態列「等待中」。
2. **遊戲中畫面（進行中）**：狀態列大字顯示最新抽出號碼 + 已完成線數；3×3 卡片已標記格有明顯像素標記、卡片鎖定（FR-3.5）；開獎紀錄依序列出、最新一顆特別強調（FR-4.3）。
3. **加賽畫面（加賽中）**：多人平手時進入 sudden death 的過場提示（「平手！進入加賽」）；僅平手者參與，顯示系統發的新 3×3 卡片與加賽開獎；達成門檻為先連 1 條線（FR-6.4／FR-6.5）。
4. **結果畫面（已結束）**：「你贏了！／ XXX 獲勝／無人獲勝」（FR-6）；以像素動畫強調獲勝線上的格子（FR-7.3）。

## 3. 管理員後台 — 現代簡約白底風

### 3.1 風格規範（刻意不用像素，延伸 `JoinRoom.vue` token）

| 類別 | 規範 |
| --- | --- |
| 整體調性 | 乾淨現代 SaaS 介面，重操作效率與資訊密度 |
| 背景 / 表面 / 邊框 | `#f4f5f7` / `#ffffff` / `#e2e5ea` |
| 文字 | `#1c2430` |
| 主要按鈕/強調 | 品牌紅 `#e63946` |
| 圓角 / 投影 / 字型 | 圓角 14px、柔和投影、系統中文字型、字型平滑開啟 |

### 3.2 需設計的後台畫面

1. **抽號控制台**：開啟後台即為此畫面（本版免登入，見 FR-1）；大顆「抽號」主按鈕（FR-4.1）；最新號碼大字 + 開獎紀錄 + 已抽/總數進度（FR-4.3）；即時顯示已達標/領先玩家清單（FR-7.4）；「開場（號碼池固定 1~36）」「結束／重設場次」控制（FR-2）；場次狀態標示（含 `加賽中`）。多人平手時提示進入加賽、顯示加賽參賽者，並於 `加賽中` 續用同一「抽號」流程（FR-6.4／FR-6.5）。

> 未來擴充：管理員登入畫面（帳號／密碼輸入框 + 登入按鈕）—— 本版免登入，暫不設計（見 `requirements.md` §8）。

## 4. 共用需求

- 響應式：手機到桌機皆正常、無水平捲動；手機上 3×3 卡片仍清楚可點（NFR-5）。
- 無障礙（NFR-4）：對比足夠；格子/按鈕有 focus 外框；可鍵盤操作；狀態以 `aria-live` 播報。
- 實作注意：賓果專案用 TailwindCSS，scratch-card 為純手寫 CSS；色票/字型/像素概念可沿用，需轉為 Tailwind（自訂 CSS 變數 + utility 或 theme extend）。
